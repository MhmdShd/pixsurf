# pixsurf v0.3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** GET search forms, async image loading, cross-page anchor jumps.

**Architecture:** layout gains form extraction + a FormValues input; ui gains a generalized status-bar Prompt; main caches the parsed DOM (re-layout without re-fetch), owns form values, builds submit URLs, and runs an async image pipeline (cache-backed fetcher, 4-worker pool, generation counter, 200ms debounced re-layout).

**Tech Stack:** existing packages; stdlib only additions (net/url, context, sync).

Spec: `docs/superpowers/specs/2026-07-31-pixsurf-v03-design.md` — READ IT FIRST; it defines all types, behaviors, and edge cases (hidden inputs, query replacement, generation filtering, prompt-deferred redraws).

Tests are the contract. Public APIs below are FIXED; implementation details may vary.

### Task 3: main — DOM cache, field editing, submit, cross-page anchors (TDD for pure helpers)

**Goal:** Wire forms end-to-end; resize/re-layout without re-fetch; anchor jumps across pages.

**Files:** Modify `main.go`; create `submit.go` + `submit_test.go` (package main, pure helpers).

**Pure helper (FIXED, tested):**
```go
// submitURL builds the GET submission URL: action stripped of its query,
// then hidden values merged with named field values (fields win on collision),
// url-encoded. Returns error for POST method or unparseable action.
func submitURL(f layout.Form, fields []layout.Field, values layout.FormValues) (string, error)
```

**Required tests (`submit_test.go`):**
- [ ] basic: action `https://s.example/search`, hidden `{lang: en}`, field `q=cats` → `https://s.example/search?lang=en&q=cats` (order via url.Values.Encode, alphabetical)
- [ ] query replacement: action with `?old=1` → old query gone
- [ ] field overrides hidden with same name
- [ ] POST → error; garbage action URL → error
- [ ] empty-name fields skipped; empty-value named field still included (`q=`)

**main wiring:**
- Cache `*dom.Doc` + page body per page; `relayout()` uses cache (no network); resize path re-layouts from cache.
- FormValues owned by app, cleared on navigate; ValuesKey from layout.
- Click on FieldAt → `Prompt(name+": ", current)`; InputEvent → store value, re-layout (shows value), then submit that field's form via submitURL → navigate. InputCancel → nothing.
- Click SubmitAt → submit form. POST/nav errors → status bar.
- URLBar action → Prompt("URL: ", ""); InputEvent in URL mode → navigate. App tracks prompt purpose (enum: none/url/field+index).
- Cross-page anchors: `click()` on link with fragment to a different page → strip fragment, navigate, on success jump to `Anchors[frag]` (pendingFrag field), missing → status note. Same-page behavior unchanged.

**Verify:** `go test ./... && go build ./... && go vet ./...` exit 0.

### Task 4: async images

**Goal:** Instant first paint; images fill in; stale-safe.

**Files:** Create `images.go` (package main); modify `main.go`.

**Design (per spec §2):**
- `imageCache` struct: mu-guarded map url→image.Image, wanted set, per-page (cleared on navigate), 50-image cap.
- Render pass uses fetcher that: cache hit → image; miss → record wanted, return error (placeholder).
- After render, spawn fetches for wanted URLs into 4-worker pool bound to a per-page `context.Context` (canceled on navigate); each success stores + sends on arrivals chan (buffered) tagged with generation int.
- Main loop: `select` over `a.u.Events()`, arrivals, debounce timer chan. Arrival with current generation → mark dirty + arm/reset 200ms timer; stale generation → drop. Timer fire → re-layout from cached DOM + draw (offset preserved, clamped). While prompt active → hold dirty, apply on prompt close.
- `--no-images` → whole pipeline off (nil fetcher as today).

**Acceptance Criteria:**
- [ ] First draw of an image-bearing page happens without waiting on image fetches (placeholders)
- [ ] Cache-hit re-render produces pixel lines (unit-testable: fake fetcher + two Render passes through the cache fetcher)
- [ ] Generation filtering: stale arrival dropped (unit test the filter decision if factored pure; otherwise code-review verified)
- [ ] `go test ./... -race` passes (concurrency!)

**Verify:** `go build ./... && go vet ./... && go test ./... -race` exit 0.

**Commit:** `feat: async image loading with per-page cache and debounced redraw`
